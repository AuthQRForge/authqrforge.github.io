AuthQRForge API Reference

You can access the API at https://authqrforge.github.io/api/authqrforge.js

AuthQRForge.generateSecret(options)

AuthQRForge.generateSecret(options) → string

Generates a cryptographically random Base32 secret suitable for TOTP.

  • options.length — number of characters (default 26).

AuthQRForge.buildUri(issuer, account, secret)

AuthQRForge.buildUri(issuer, account, secret) → string

Builds the otpauth://totp/ URI that authenticator apps scan or import.

  • issuer — the app or service name.
  • account — the user identifier (email, username, etc.).
  • secret — Base32 secret.

AuthQRForge.generate(issuer, account, options)

AuthQRForge.generate(issuer, account, options) → { secret, uri, issuer, account }

Convenience wrapper. Creates a new secret and returns it together with the URI and identity in one call.

  • options.secret — supply your own secret instead of generating one.
  • options.length — length of the generated secret (default 26).

AuthQRForge.getCode(secret, options)

AuthQRForge.getCode(secret, options) → string

Returns the TOTP code that is valid right now for the given secret.

  • options.period — time step in seconds (default 30).
  • options.digits — number of digits (default 6).
  • options.timestamp — milliseconds since epoch (default Date.now()).

AuthQRForge.verify(secret, code, options)

AuthQRForge.verify(secret, code, options) → { valid, reason }

Checks whether a user-supplied code matches the secret. Returns a result object describing success or failure.

  • options.window — number of time steps to accept on each side (default 1).
  • options.period — time step in seconds (default 30).
  • options.digits — number of digits (default 6).
  • options.timestamp — milliseconds since epoch (default Date.now()).

Possible reason values: "match", "no_match", "invalid_format", "missing_secret".

AuthQRForge.drawQR(canvas, uri, options)

AuthQRForge.drawQR(canvas, uri, options) → boolean

Renders a QR code for the given URI onto an existing <canvas> element.

  • canvas — a DOM canvas element to draw into.
  • uri — the otpauth:// URI to encode.
  • options.foreground — module color (default "#000000").
  • options.background — background color (default "#ffffff").

Returns true on success, false if the payload is too large.

AuthQRForge.downloadPng(canvas, options)

AuthQRForge.downloadPng(canvas, options) → void

Triggers a browser download of the canvas contents as a PNG file.

  • canvas — the canvas element to export.
  • options.filename — download filename (default "qr.png").

<!DOCTYPE html>
<html lang="en">

<script src="https://authqrforge.github.io/api/authqrforge.js"></script>
<script>
let demoSecret = null;
let demoUri = null;

function run1() {
  document.getElementById('out1').textContent = AuthQRForge.generateSecret();
}
function run2() {
  const s = AuthQRForge.generateSecret();
  document.getElementById('out2').textContent = AuthQRForge.buildUri('MyApp', 'user@example.com', s);
}
function run3() {
  const r = AuthQRForge.generate('MyApp', 'user@example.com');
  demoSecret = r.secret;
  demoUri = r.uri;
  document.getElementById('out3').textContent = JSON.stringify(r, null, 2);
}
function run4() {
  const s = demoSecret || AuthQRForge.generateSecret();
  demoSecret = s;
  document.getElementById('out4').textContent = AuthQRForge.getCode(s) + '  (secret: ' + s + ')';
}
function run5() {
  const s = demoSecret || AuthQRForge.generateSecret();
  demoSecret = s;
  const code = document.getElementById('in5').value;
  document.getElementById('out5').textContent = JSON.stringify(AuthQRForge.verify(s, code), null, 2);
}
function run6() {
  if (!demoUri) {
    const r = AuthQRForge.generate('MyApp', 'user@example.com');
    demoSecret = r.secret;
    demoUri = r.uri;
  }
  const canvas = document.getElementById('cv6');
  AuthQRForge.drawQR(canvas, demoUri, { foreground: '#0d1117', background: '#ffffff' });
  document.getElementById('out6').textContent = demoUri;
}
function run7() {
  const canvas = document.getElementById('cv6');
  AuthQRForge.downloadPng(canvas, { filename: 'authqrforge-demo.png' });
}
</script>

</body>
</html>
